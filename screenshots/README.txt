SCREENSHOTS-ORDNER
===================

Dieser Ordner ist für Screenshots der GUI vorgesehen.

ANLEITUNG ZUM ERSTELLEN VON SCREENSHOTS:
--------------------------------------

1. GUI starten:
   java StartGUI

2. Testfälle durchführen (siehe Haupt-README.md für Beispiele)

3. Screenshots erstellen:
   - Windows: Win + Shift + S (Ausschneiden und Skizzieren)
   - Mac: Cmd + Shift + 4 (ausgewählter Bereich)
   - Linux: Shift + PrtScn (ausgewählter Bereich)

4. Bilder hier speichern mit folgenden Namen:
   - gui_start.png          (Startbildschirm)
   - test_addition.png      (Additionstest)
   - test_subtraktion.png   (Subtraktionstest)
   - test_multiplikation.png (Multiplikationstest)
   - test_division.png      (Divisionstest)
   - test_speichern.png     (Speichern-Test)
   - test_bus.png           (Bus-Anbindung Test)
   - test_reset.png         (Zurücksetzen Test)

5. In der README.md die Platzhalter durch die tatsächlichen Bilder ersetzen
